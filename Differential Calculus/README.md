# Math 101: Differential Calculus - Midterm Exam Simulators

Interactive exam practice suite designed for King Saud University (KSU) Common First Year Math 101 Midterm preparation (Targeting 25/25).

## Features
- **Full Mock Exams (`index.html`, 5 exams)**: complete practice exams to sit in 90 minutes. Modeled on the KSU CFY 1446H/1447H midterm papers (Questions 1-4, 25.0 marks total).
  - Question 1: 6 MCQs (3.0 marks)
  - Question 2: Rational / Irrational classification (4.0 marks) + rational inequalities & compositions (4.0 marks)
  - Question 3: One-to-one functions, inverses & exact trig values (6.0 marks)
  - Question 4: Limits (8.0 marks)
- **Quick Drills (`math101_practice.html`, 6 sets)**: short 10-question sets (60 questions total) for practising weak topics and common traps.
- **90-minute exam clock** per version, starting on your first answer and auto-grading when time runs out.
- **Auto-grading** out of 25.0 with a per-question breakdown, the correct option highlighted, and step-by-step solutions.
- **Shuffled answer positions**, re-shuffled each time you retry a version, so the key is never memorisable by letter.
- **Progress saved in the browser**: answers, grades and time survive a page refresh.
- Light and dark mode follow your system setting.

## Usage
Double-click `index.html` to open the exam simulator in any browser (an internet connection is needed to load the styling library).
