# Math 101: Differential Calculus - Midterm Exam Simulators

Interactive exam practice suite designed for King Saud University (KSU) Common First Year Math 101 Midterm preparation (Targeting 25/25).

## Features
- **Official Exam Replica Format (5 Versions)**: Based directly on the official KSU CFY 1446H/1448H midterm paper (Questions 1-4, 25.0 marks total).
  - Question 1: 10 MCQs (5.0 marks)
  - Question 2: Rational / Irrational Number Classification (6.0 marks)
  - Question 3: Free-response Inequalities, Domains & Inverses (6.0 marks)
  - Question 4: Exact Trig Values & Limits (8.0 marks)
- **Practice Suite (6 Versions)**: 60 drill questions targeting tricky edge cases and common traps.
- **Timer & Auto-Grading**: Real-time scoring out of 25.0 with full step-by-step explanations.

## Usage
Simply double-click `index.html` to open the exam simulator in any browser.
